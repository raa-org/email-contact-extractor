# Security policy

Please **do not** open public GitHub issues for vulnerabilities.

Report them privately via [GitHub Security Advisories](https://github.com/raa-org/email-contact-extractor/security/advisories/new) on this repository.

When reporting, it helps to include the app version (Help → the version shown in the
title bar or `package.json`), the operating system, and — if the issue involves a
mailbox — a synthetic reproduction rather than real message data.
